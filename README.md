## 🎉 How to Use  
1. Clone the repo:  
   ```bash
   git clone https://github.com/nikitayadav19/HappyBirthdayGF.git
   ```

## Customize this copy

The birthday headings in [index.html](./index.html) and
[cause.html](./cause.html) are personalized for Monisha.

- Replace `d1.jpg`, `d2.jpg`, and `d3.jpg` with your own JPEG photos, keeping
  the exact filenames. These appear in [last.html](./last.html); `d1.jpg`
  also appears in [cause.html](./cause.html). The original photos remain
  until you replace them.
- Edit the greeting in [script.js](./script.js), birthday wishes in
  [cause.js](./cause.js), and gallery captions in [last.html](./last.html)
  if desired.
- Open `index.html` in a browser to preview. An internet connection is
  needed for the externally hosted GSAP animations and Google Fonts.

## Publish a shareable link

This is a static site with no backend, database, or build step. Navigation
remains `index.html` -> `cause.html` -> `last.html`, so the address changes
between pages, but visitors only need the initial link.

1. Replace the original photos before publishing. Photos and messages
   on a public site are publicly accessible; this site has no password protection.
2. Upload or push your customized files to a repository you own on GitHub.
   The cloned repository's `origin` points to the original author's repository;
   change it to your own repository before pushing.
3. In your repository's **Settings > Pages**, select **Deploy from a branch**,
   choose the branch containing your files and the **/(root)** folder, and save.
4. Once deployment finishes, share the URL shown by GitHub Pages, typically
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`.

Cloning alone does not publish a site. The live demo above belongs to the
original author and does not reflect your local changes.
